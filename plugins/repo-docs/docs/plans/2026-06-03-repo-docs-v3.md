## Fixed contracts (lock these BEFORE parallel work)

### `score_docs.py` — advisory 0–100 rubric over a single doc

Public: `score_doc(text, root=None, doc_path=None, index=None, weights=None, threshold=DEFAULT_THRESHOLD, size_target=DEFAULT_SIZE_TARGET, size_cap=DEFAULT_SIZE_CAP) -> dict`, plus the six pure dimension scorers and `main(argv=None) -> int`.

`score_doc` returns:

```python
{
  "score": int,                 # 0..100, rounded; weighted mean of applicable dimensions
  "threshold": int,             # default 70
  "above_threshold": bool,      # score >= threshold
  "dimensions": {               # one entry per dimension
    "size_fit":      {"score": float, "weight": float, "applicable": bool, "detail": str},
    "evidence":      {...},
    "ref_stability": {...},
    "examples":      {...},
    "boundaries":    {...},
    "drift":         {...},      # applicable ONLY when root is given (needs the filesystem)
  },
}
```

- Each dimension `score` ∈ [0.0, 1.0]. **`drift` is `applicable: False` (excluded, weights renormalized) when `root is None`** — it cannot be measured without the filesystem. Never give an unmeasurable dimension 0 (that would punish a doc we simply can't measure).
- Final score = `round(100 * Σ(weight_i · score_i) / Σ(weight_i))` over *applicable* dimensions only.
- **Default weights (`[SYNTHESIS]`, sum 1.0):** `size_fit 0.15, evidence 0.30, ref_stability 0.15, examples 0.15, boundaries 0.15, drift 0.10`.
- Constants: `DEFAULT_THRESHOLD = 70`, `DEFAULT_SIZE_TARGET = 12288` (12 KiB), `DEFAULT_SIZE_CAP = 32768` (Codex cap).
- **Dimension definitions (own these; they ARE the calibration):**
  - **size_fit** — `nbytes = len(text.encode("utf-8"))`. `1.0` if `nbytes <= size_target`; `0.0` if `nbytes >= size_cap`; else linear `(size_cap - nbytes)/(size_cap - size_target)`. Penalizes only largeness (a small doc is size-fit; its other gaps show elsewhere).
  - **evidence** — among *content lines* (non-blank, non-heading, non-fence, non-table-separator, non-`---` lines whose bullet/number marker stripped body has ≥4 alphabetic words), the fraction that bear evidence. A line bears evidence if it contains an inline backtick span OR the string `NEEDS VERIFICATION`. `0.0` if there are no content lines.
  - **ref_stability** — `v = len(no_line_refs.find_violations(text))`; `1.0` if `v == 0` else `max(0.0, 1.0 - 0.5*v)`.
  - **examples** — `signals = text.count("✅") + text.count("🚫") + len(_fenced_blocks(text)) + len(re.findall(r"\\b(e\\.g\\.|for example)\\b", text, re.I))`; score `min(1.0, signals/4.0)`.
  - **boundaries** — `1.0` if all three tier emojis (`✅`, `⚠️`, `🚫`) are present; else `0.5` if a heading matching `(?im)^#+\\s.*(boundar|contract|guardrail)` exists OR at least one tier emoji is present; else `0.0`.
  - **drift** — applicable only with `root`. `f = len(drift_check.find_drift(root, [doc_path], index))` (index optional; dead-symbol check skipped when index is None — `find_drift` already does this); `1.0` if `f == 0` else `max(0.0, 1.0 - 0.2*f)`.
- CLI: `score_docs.py [--root DIR] [paths/globs...] [--json] [--strict] [--threshold N] [--weights "k=v,k=v"] [--index FILE] [--size-target N] [--size-cap N]`. Default paths = all `*.md` under root. Scores each doc; prints a per-doc report (or a JSON array of `{"file", **score_doc_result}`). **Exit 0 by default even for below-threshold docs; `--strict` → exit 1 if any doc is below threshold; exit 2 on bad `--root` or malformed `--weights`.**
- `--weights` parsing: comma-separated `name=float`; unknown name or non-float → exit 2. Provided values override the defaults for those names; the merged weights are then renormalized over applicable dimensions.

### `conflict_scan.py` — advisory contradictory-rule detector (low false-positive)

Public: `find_conflicts(text) -> list[dict]`, `main(argv=None) -> int`. Each finding: `{"category", "lines": [int, int], "detail", "a": str, "b": str}`.

- A curated `CONFLICTS` table of antonym rule pairs; each entry: `category`, `a=(regex, kind)`, `b=(regex, kind)`, `detail`. `kind` ∈ `"rule" | "instance"`.
- A finding fires when **both** sides match in the doc. For a side with `kind == "instance"`, matches on a **prohibition/negation line are skipped** (so an anti-pattern shown as the forbidden thing is NOT a conflict). Negation context = a line containing any of `🚫 ❌ ⚠️` or, case-insensitively, `not`, `never`, `avoid`, `don't`/`do not`, `instead`, `rather than`, `deprecat`, `legacy`, `away from`, `no default`.
- Default `CONFLICTS` (low-FP, prescriptive forms only):
  1. `indentation` — `a`=`\b(use|prefer|indent\w* with|indent\w* using) tabs\b` (rule) · `b`=`\b(use|prefer|indent\w* with|indent\w* using)\s+(?:\d+\s+)?spaces\b` (rule).
  2. `quotes` — `a`=`\b(use|prefer)\s+single quotes\b` (rule) · `b`=`\b(use|prefer)\s+double quotes\b` (rule).
  3. `semicolons` — `a`=`\b(use|require|always use)\s+semicolons\b|semicolons?\s+(?:are\s+)?required\b` (rule) · `b`=`\bno semicolons\b|\bomit semicolons\b|\bsemicolon-free\b|\bwithout semicolons\b|\bnever\s+(?:use\s+)?semicolons\b` (rule).
  4. `exports` — `a`=`named exports?\s+only\b|no default exports?\b|avoid default exports?\b|don'?t use default exports?\b|never use default exports?\b` (rule) · `b`=`\bexport default\b` (**instance** — negation-filtered).
- All `a`/`b` regexes compiled with `re.IGNORECASE` (the `export default` instance matches literal source either way).
- CLI: `conflict_scan.py [--root DIR] [paths/globs...] [--json] [--strict]`. Default paths = all `*.md` under root. Prints findings per file (or JSON array of `{"file", **finding}`). **Advisory: exit 0 by default even with findings; `--strict` → exit 1 if findings; exit 2 on bad `--root`.** Per-doc detection (a conflict spanning two files is a documented limitation).

### `eval_harness.py` — Tier-A objective doc-quality delta

Public: `measure(root, doc_paths, index=None) -> dict`, `compare(a, b) -> dict`, `main(argv=None) -> int`.

`measure` returns:

```python
{
  "docs": [relpath, ...],          # docs measured (relative to root)
  "count": int,
  "score": float,                  # mean score_docs score across docs (0..100)
  "total_bytes": int,              # sum of doc bytes
  "under_cap": bool,               # total_bytes < 32768
  "evidence_density": float,       # mean evidence dimension (0..1)
  "path_refs_total": int,
  "path_refs_resolved": int,
  "path_resolve_pct": float,       # resolved/total*100 (100.0 if total == 0)
  "line_refs": int,                # total line-number refs
  "duplication_findings": int,     # dup_detect.check count
}
```

`compare(a, b)` → `{metric: {"a": a[metric], "b": b[metric], "delta": a-b}}` for the numeric metrics (`delta = a − b`, i.e. how much A beats B).

- CLI: `eval_harness.py --root REPO --dir-a DIR --dir-b DIR [--label-a A] [--label-b B] [--index FILE] [--json]`. Measures the `*.md` in each dir against `REPO`'s real source, prints a side-by-side table + deltas. Exit 0 (it is a report); exit 2 on bad `--root`/`--dir-*`.
- Reuses: `score_docs.score_doc`, `path_exists.check_doc`/`extract_path_tokens`, `no_line_refs.find_violations`, `dup_detect.check`.

# Doc-quality scoring rubric (`score_docs.py`)

`score_docs.py` rates a doc 0–100 across six dimensions. It is an **advisory
proxy**, never the sole gate (DESIGN §13 #16, §12): it reports a score, it does
not block. The blocking gate (`run_gate.sh`) decides pass/fail; the score guides
*improvement*.

## Dimensions

| Dimension | Weight | Measures | 1.0 means |
|---|---|---|---|
| `size_fit` | 0.15 | bytes vs the budget (target 12 KiB → Codex 32 KiB cap) | at/under the 12 KiB target |
| `evidence` | 0.30 | fraction of substantive lines bearing a backticked ref or `NEEDS VERIFICATION` | every claim is evidence-gated |
| `ref_stability` | 0.15 | absence of line-number references | no `path.ext:NNN` / `line NNN` |
| `examples` | 0.15 | presence of ✅/🚫 examples, fenced snippets, "e.g." | concrete examples throughout |
| `boundaries` | 0.15 | a Boundaries/Contracts section with ✅/⚠️/🚫 tiers | all three tiers present |
| `drift` | 0.10 | dead paths/symbols + doc-vs-code mtime (needs `--root`) | nothing stale |

Final score = `round(100 · Σ(weightᵢ·scoreᵢ) / Σ(weightᵢ))` over **applicable**
dimensions. `drift` is excluded (weights renormalized) when no `--root` is given —
an unmeasurable dimension is dropped, never scored 0.

## Threshold & calibration

- Default threshold: **70** (`--threshold N`). The v3 quality bar is "every
  generated doc scores above threshold."
- The weights are **`[SYNTHESIS]` — reasoned, not vendor-blessed.** They are
  calibrated so the annotated good example (`examples/good/menv-AGENTS.md`) scores
  high and the annotated bad example (`examples/bad/AGENTS.md`) scores low. Tune
  them for your repo with `--weights "evidence=0.4,size_fit=0.1,..."`.

## Use

`score_docs.py [--root DIR] [docs...] [--json] [--strict] [--threshold N] [--weights ...]`.
Advisory: exit 0 even below threshold; `--strict` exits 1 if any doc is below it.
See `references/evidence-levels.md` for the evidence-gating rule the `evidence`
