## Fixed JSON contracts for the new extractors (lock these BEFORE parallel work)

All three extractors are **pure Python stdlib** (no ripgrep dependency — consistent with `scan_repo.py`/`extract_scripts.py` and testable everywhere). Each: `<name>.py [--root DIR] [--json]`; default human output (TSV-ish), `--json` emits the array; exit 0 on success (even when empty), 2 on bad `--root`. `file` is always a **relpath-from-root with no `./` prefix**, matching `extract_symbols.sh`.

- **`extract_routes.py`** → `[{"method","path","handler","file"}]`
  - `method`: uppercase HTTP verb (`GET POST PUT PATCH DELETE HEAD OPTIONS`) or `ALL` for catch-all (`app.all`, `app.use`-style is NOT captured — too noisy).
  - `path`: the route string literal (e.g. `/api/orders`, `/users/:id`).
  - `handler`: handler symbol name when identifiable (bare-identifier arg, or the `def` name under a Python decorator), else `""`.
- **`extract_schema.py`** → `[{"entity","kind","source","file"}]`
  - `entity`: table/model name as written.
  - `kind`: `"table"` | `"model"`.
  - `source`: `"prisma"` | `"sql"` | `"django"`.
- **`extract_events.py`** → `[{"name","action","file"}]`
  - `name`: topic/queue/event string literal.
  - `action`: one of `emit` `publish` `subscribe` `consume` (the matched verb). `.on(...)` and `.send(...)` are EXCLUDED by default (noise).
- **`drift_check.py`** → `[{"doc","line","kind","detail"}]` (advisory)
  - `kind`: `"dead-path"` | `"dead-symbol"` | `"stale-vs-code"`.
  - Reuses `path_exists.check_doc`, `symbol_exists.extract_refs`/`check`, and a git-or-fs mtime comparison.
  - CLI adds `[--index INDEX.json]`, `[paths/globs...]`, `[--strict]`. **Default exit 0 even with findings** (advisory). `--strict` → exit 1 if findings. Exit 2 on bad `--root`. Symbol/index unavailable → skip the dead-symbol check (don't fail).

### Task 1: `extract_routes.py`

**Files:** Create `scripts/extract_routes.py`; Test `scripts/tests/test_extract_routes.py`.

**Public functions:** `extract(root) -> list[dict]`, `main(argv=None) -> int`. Also expose `_from_js_text(text, relpath)` and `_from_python_text(text, relpath)` for unit testing.

**Algorithm:** Walk the tree skipping the standard ignore set (`.git node_modules dist build .venv venv __pycache__ vendor target .next coverage`). For `.js/.jsx/.ts/.tsx/.mjs/.cjs` files apply the JS regex; for `.py` files apply the Python regexes.

- **JS/TS (Express/Koa/Fastify/router):** regex
  `r"\b(?:app|router|r|fastify|server|api)\.(get|post|put|patch|delete|head|options|all)\s*\(\s*[`'\"]([^`'\"]+)[`'\"]\s*(?:,\s*([A-Za-z_$][\w$]*)\s*[,)])?"`
  → method = group(1).upper() (`all` → `ALL`); path = group(2); handler = group(3) or `""` (only a bare identifier counts; inline arrow/anon → `""`).
- **Python decorator form `@app.get("/x")`:** regex
  `r"@(?:app|router|api|bp|blueprint)\.(get|post|put|patch|delete|head|options)\s*\(\s*[`'\"]([^`'\"]+)[`'\"]"` → method/path; handler = the name from the first `def <name>` within the next ~3 non-blank lines, else `""`.
- **Python `@app.route("/x", methods=[...])`:** regex
  `r"@(?:app|router|api|bp|blueprint)\.route\s*\(\s*[`'\"]([^`'\"]+)[`'\"]\s*(?:,\s*methods\s*=\s*\[([^\]]*)\])?"` → path = group(1); methods = parsed string literals from group(2) (uppercased) or `["GET"]` default; emit one record per method; handler from following `def`.

Dedup by `(method, path, handler, file)`.

### Task 4: `drift_check.py` (advisory)

**Files:** Create `scripts/drift_check.py`; Test `scripts/tests/test_drift_check.py`.

**Public functions:** `find_drift(root, doc_paths, index) -> list[dict]`, `main(argv=None) -> int`, `_mtime(root, relpath) -> float` (git commit time `git -C root log -1 --format=%ct -- relpath`; fall back to `os.path.getmtime` when git missing/untracked/returns empty).

**Algorithm:** Reuse existing validators (same `scripts/` dir, importable):

```python
import path_exists        # check_doc(text, root) -> [{"token","line"}]
import symbol_exists      # extract_refs(text) -> [{"symbol","file","line"}]; check(refs, index, root)
```

For each doc file:

1. **dead-path:** `path_exists.check_doc(text, root)` → each becomes `{"doc": rel, "line": r["line"], "kind": "dead-path", "detail": r["token"]}`.
2. **dead-symbol:** if `index` is not None, `symbol_exists.check(symbol_exists.extract_refs(text), index, root)` → each becomes `{"doc","line","kind":"dead-symbol","detail": "<symbol> in <file> (<reason>)"}`. If index is None → skip this check.
3. **stale-vs-code:** collect the existing source files this doc references — backticked path tokens that resolve (`path_exists.extract_path_tokens` filtered to existing) plus the `file` from each symbol ref that exists. For each such source file, if `_mtime(root, source) > _mtime(root, doc)` → `{"doc","line": 0,"kind":"stale-vs-code","detail": "<source> is newer than this doc"}`. Dedup stale findings by `(doc, source)`.

`main`: resolve docs (default `*.md` under root, or explicit paths/globs); load index via `--index` or by building it through `extract_symbols.sh` (like `symbol_exists`), but **on any index failure set index=None and continue** (advisory — never hard-fail on a missing index). Print findings (human or `--json`). **Return 0 by default; with `--strict` return 1 if findings.** Bad `--root` → 2.
